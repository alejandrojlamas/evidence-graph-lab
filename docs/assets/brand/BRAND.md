# Identidad visual de Red Privada

La identidad combina la disciplina del archivo periodístico con la lectura moderna de grafos.
La columna vertical del símbolo representa el oficio editorial; sus nodos y enlaces convierten
esa columna en una red de evidencia con forma de **R**.

## Principios

- **Documental, no sensacionalista.** La red organiza pistas; no acusa ni dramatiza.
- **Original.** No utiliza retratos, firmas, facsímiles, cabeceras ni citas de Manuel Buendía.
- **Trazable.** Cada conexión visual parte de un nodo y conserva una ruta legible.
- **Sobria.** El color óxido señala revisión pendiente; nunca funciona como alarma automática.

## Paleta

| Nombre | Hexadecimal | Uso |
| --- | --- | --- |
| Papel | `#F3E8D0` | Fondo claro y texto sobre tinta |
| Tinta | `#1D2825` | Texto y estructura principal |
| Verde archivo | `#3F5A50` | Relaciones secundarias |
| Óxido editorial | `#6E3F35` | Evidencia que requiere atención |
| Latón | `#B8893E` | Detalle decorativo, no texto pequeño |
