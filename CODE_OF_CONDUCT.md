# Código de conducta de Red Privada

## Nuestro compromiso

Red Privada busca una comunidad rigurosa, respetuosa y abierta a perspectivas diversas. Nos
comprometemos a mantener los espacios del proyecto libres de acoso y discriminación, sin importar
experiencia, identidad, origen, edad, discapacidad, apariencia, religión, nacionalidad u otra
característica personal.

El desacuerdo técnico es bienvenido cuando se expresa con argumentos verificables y consideración
por las demás personas.

## Conducta esperada

- Tratar a cada participante con respeto y buena fe.
- Criticar ideas, decisiones y código sin descalificar a quien los presenta.
- Explicar supuestos, reconocer incertidumbre y corregir errores con transparencia.
- Dar y recibir retroalimentación concreta, relevante y orientada a mejorar el proyecto.
- Respetar la privacidad, los derechos de autor y las condiciones de las fuentes utilizadas.
- Priorizar la seguridad de las personas cuando una conversación o ejemplo pueda causar daño.

## Conducta inaceptable

- Acoso, amenazas, intimidación o ataques personales.
- Lenguaje o imágenes sexualizadas, discriminatorias o deliberadamente humillantes.
- Publicar o solicitar datos personales, credenciales, comunicaciones privadas o material
  confidencial sin autorización.
- Utilizar el proyecto para hostigar, perfilar o formular acusaciones contra personas.
- Manipular evidencia, ocultar procedencia o presentar señales exploratorias como hechos probados.
- Interrumpir de forma sostenida la colaboración o ignorar deliberadamente las normas del
  proyecto.

## Alcance

Este código se aplica a *issues*, *pull requests*, revisiones, discusiones y demás espacios donde
una persona participe en nombre de Red Privada. También se aplica a la publicación de artefactos o
resultados que afirmen representar al proyecto.

## Reportes y aplicación

No publiques en un *issue* información personal sobre un incidente. Usa las herramientas privadas
de denuncia y bloqueo de GitHub para reportar abuso o contenido que infrinja sus políticas. Si el
reporte se refiere a una vulnerabilidad técnica, utiliza únicamente
[GitHub Security Advisories](https://github.com/alejandrojlamas/red-privada/security/advisories/new),
según se explica en [SECURITY.md](SECURITY.md).

Quienes mantienen el proyecto pueden editar o retirar contribuciones, comentarios u otras
participaciones incompatibles con este código, y pueden limitar temporal o permanentemente la
participación. La medida se determinará según el contexto, la gravedad, la reincidencia y el riesgo
para otras personas. No se garantiza un tiempo específico de respuesta.

Este proyecto no es un canal de emergencia. Ante un riesgo inmediato para una persona, contacta a
los servicios locales apropiados.
